# Fonts

The site's two typefaces, served from here instead of from Google Fonts. The
files are the WOFF2 subsets Google Fonts serves (Latin, Latin Extended,
Cyrillic, Greek and Vietnamese), and `fonts.css` keeps Google's faces, weights
and unicode ranges, so a browser only downloads the subsets a page uses.
Every page preloads the four Latin files.
